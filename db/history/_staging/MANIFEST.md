# Staged sources

Primary texts, scans and page captures fetched by the first research run before
it was cut off. Kept here so a later run does not spend the ship's satellite
link fetching them again. Plain OCR text unless the extension says otherwise;
the OCR is raw, so quote carefully and check spellings against the printed page.

Each topic directory has a `RESUME.md` naming the items relevant to it.

## Images and metadata
`boas-fig54*.png`, `boas-plateII.jpg`, `boas-plateIV.png` are figures from Boas'
*The Central Eskimo* including Inuit-drawn charts. `parry1.jpg`, `parry2.jpg` are
Parry plates. `commons-meta.json`, `commons-search.txt`, `commons.txt`,
`imageinfo.json`, `gerritsz.json`, `titles.txt` and `info_*.txt` are Wikimedia
Commons search and licence lookups — check them before querying the Commons API
again, which rate-limited the first run.

`wiki/` holds Wikipedia page text — but about ten of the files are Wikimedia
error pages, not articles (Norðrsetur, Nanook_site, Skrælingi,
Peter_Schledermann, Grœnlendinga_saga among them): check the first lines
before trusting one. The good ones cover Norse Greenland, Helluland, the sagas and
the Ellesmere sites. Orientation only: cite the underlying sources.
