## Notes on Attribution and Interpretation

**Frobisher naming patterns:**
- Heavy emphasis on patrons and investors (Warwick family, Queen Elizabeth)
- Some crew members honored (Hall the pilot, the smith, Jackman)
- Geographic features named by analogy (Charing Cross from London)
- Ship names follow religious tradition (Gabriel, Michael, Ayde)

**Davis naming patterns:**
- Strong emphasis on West Country connections (Totnes, Exeter, Devon)
- Named after patrons, investors, and personal friends
- Sanderson as chief backer gets "Hope" named after him (signifying prospects for wealth/passage)
- Cape Chidley honors a deceased friend

**Unclear or missing from texts:**
- Meta Incognita: mentioned as the region name but no explicit naming narrative found in the Best text (1578)
- Lok's Land: mentioned in the memory file but not found in the Best text search
- Sussex Islands: referenced in search results but passage not fully extracted
- The full identifying details for some crew members (e.g., which "Jackman" the sound was named after)
- Modern equivalences for several minor place names remain uncertain
