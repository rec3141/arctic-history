# Named animals, by source

Extraction table from run 1 (2026-09-09). One line per animal row, with the
bibkey it was taken from; the page reference is in each row's note in the
database. Method: a regex sweep of every .txt under db/history for the naming
constructions (`the dog X`, `a dog named X`, `X, my dog`, `dogs called X`,
`"X" the dog`, `poor old X`) followed by hand-reading of each hit in context
with its nearest printed page marker. The candidate-passage dump held 234
passages drawn from 470 texts.
