# Extraction notes

Keyword extractions made from the primary texts held in this repository, one
file per source group. Each line is: line number in the source text, the date as
written, the place or position, the number and unit exactly as written, the kind
of observation, the observer or ship, the printed page, and a short phrase.

**These are working lists, not the record.** The rows entered in the database
were re-verified against the printed page before entry, and a good many lines in
these files were not entered because they carry no date, no position, or a page
number the extraction guessed wrong. Two known traps:

- The OCR of Parry's journals carries the month in a running side-note that is
  often far from the passage. Dates in `parry1824-water.md` must be checked against the day-of-week marginal notes
  (`Sat. 16.`) and the voyage's own chronology; several in the extraction are
  wrong by three months.
- The line numbers in `schott-hayes-water.md` do not correspond to the raw text
  file and should be treated as approximate; the Port Foulke tidal figures in
  the database were found by searching the text directly.

The extraction for Parry's first voyage (1819-20) was made but not saved to a
file; its rows are in the database and can be regenerated from
`journalofvoyagef00inparr.txt` if needed.

Sources not yet mined: the Franklin-search and McClure blue books, Sutherland
1852, Collinson 1889, Sverdrup's *Nyt land* (Norwegian, so the English keyword
pattern found nothing), and the modern DFO section data for Nares Strait.
