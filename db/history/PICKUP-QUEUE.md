# Hard-copy pickup queue

(or elsewhere) when back in Winnipeg. Grid adds a line when a request cannot be
filled electronically; the person clears it and answers the request. Holds are
NOT placed automatically: "Request for pickup" in the catalogue needs a pickup
library and a body to collect it, so the person places it themselves when the
timing works.
